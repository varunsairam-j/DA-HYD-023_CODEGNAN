\# Data Analytics Learning Journey



Welcome to my Data Analytics learning repository!



This repository documents my learning journey at Codegnan, covering programming, database management, data analysis, spreadsheet applications, and data visualization.



The objective is to strengthen my technical knowledge through consistent learning, hands-on practice, and practical exercises.

Learning programming fundamentals and problem-solving using Python.



Topics include:

\- Variables and Data Types

\- Conditional Statements and Loops

\- Strings and Collections

\- Functions and Modules

\- Object-Oriented Programming (OOP)

\### 2. SQL

Learning relational database concepts and querying data using SQL.



Topics include:

\- Database and Table Management

\- SQL Constraints and Data Types

\- Data Manipulation and Retrieval

\- Joins and Subqueries

\- Aggregate and Window Functions

Learning spreadsheet operations and data analysis using Microsoft Excel.



Topics include:

\- Excel Fundamentals

\- Formulas and Functions

\- Statistical Functions

\- Logical and Lookup Functions

\- Data Validation and Conditional Formatting

\- Charts and Data Visualization

Learning the concepts and techniques involved in analyzing data and extracting meaningful insights.



Topics include:

\- Data Analytics Fundamentals

\- Data Cleaning and Preprocessing

\- Exploratory Data Analysis (EDA)

\- Descriptive Statistics

\### 5. Power BI

Learning business intelligence and data visualization using Microsoft Power BI.



Topics include:

\- Data Import and Transformation

\- Power Query

\- Data Modeling and Relationships

\- DAX (Data Analysis Expressions)

\- Reports and Interactive Dashboards
